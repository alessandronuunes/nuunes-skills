# nuunes-skills

Coleção de skills reutilizáveis para escrita em português brasileiro.

## Skills

### Linguagem humana (`escrita-artigos-ptbr`)

Escreve e revisa artigos, posts, tutoriais e guias em PT-BR com voz humana — foco em ritmo de frase, pontuação e tom autoral, sem cara de texto gerado por máquina.

Arquivos:

- `Linguagem humana/skill.md` — instruções principais
- `Linguagem humana/references/` — antipadrões, pontuação/ritmo e voz

## Uso

Copie a pasta da skill para o diretório de skills do seu agente, ou clone este repositório e aponte para a skill desejada.
